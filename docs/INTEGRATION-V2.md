# 캔버스 v2 통합 검증 (2026-11-03)

## 병합과 범위

- 시작 시 미커밋 변경이 없는 `codex/firestore-projects`에서 최신 `origin/main`(7d841ea)을 병합했습니다. Google 로그인 #1과 캔버스 개편 #7이 포함됩니다.
- 실제 텍스트 충돌은 `src/App.jsx` 한 곳이었습니다. main의 캔버스 첫 화면과 기존 Firestore 계정 관리 생명주기를 함께 유지했습니다.
- store·학습 실행 코드의 자동 병합 결과도 점검했습니다. main의 skip connection·Add·VLM 처리와 Firestore의 늦은 학습 결과 차단을 모두 유지합니다.
- `graph.js`, `layers.js`, `code.js`, Google 로그인, AI 튜터, 배포 설정에 별도 수정은 하지 않았습니다. main의 해당 파일을 그대로 사용합니다.
- main 브랜치에는 커밋/push하지 않으며, 기존 PR #4만 업데이트합니다. 실제 Firebase 규칙 게시·운영 데이터 쓰기·배포는 하지 않습니다.

## 새 UI에 연결한 방식

- 캔버스 상단 로그인 버튼 옆에 **저장·불러오기**를 배치했습니다.
- `ProjectSession`은 화면 이동 중에도 유지돼, 3D/코드 화면에서 계정이 바뀌어도 이전 사용자 작업을 초기화합니다.
- 프로젝트 불러오기와 계정 초기화는 `view: "canvas"`, `panel: "data"`로 돌아옵니다. 제거된 `view: "main"`은 사용하지 않습니다.
- 프로젝트 변경 시 캔버스를 다시 맞추고 데이터 패널을 새로 만듭니다. 이전 프로젝트의 데이터셋 요청·로컬 입력 상태가 섞이지 않도록 합니다.
- 데이터셋 구조 재조회가 저장된 유효 split을 무조건 train으로 덮어쓰지 않도록 최소 수정했습니다.
- 프로젝트 대화상자 안의 Delete/Backspace가 뒤쪽 캔버스의 블록을 지우지 않도록 막았습니다.

## 저장 형식과 호환성

- 새 저장 형식은 schemaVersion 2입니다. 기존 그래프·클래스·설정·시각에 `dataset` 메타데이터를 추가합니다.
- dataset에는 repo·config·split과 fields의 image/question/answer/list 열 이름만 들어갑니다. 사진·행 데이터·미리보기·학습 가중치·인증 토큰은 포함하지 않습니다.
- v1 읽기를 지원합니다. dataset이 없는 문서는 안전한 기본값으로 복원하며, 현재 사용자나 이전 프로젝트의 dataset을 이어받지 않습니다. 다음 저장은 v2로 변환하고 createdAt은 보존합니다.
- 규칙은 v1/v2를 모두 허용하되, v2에서는 크기 제한이 있는 dataset 메타데이터를 요구하고 미리보기·이미지 필드 추가는 거부합니다. 운영 서버에 적용하려면 별도 규칙 검토·게시가 필요합니다.

## 검증 결과

- `npm run build` 성공. 큰 JavaScript 청크 경고는 남아 있습니다.
- 기존 테스트 + 신규 v2 회귀 테스트 + Firestore Emulator: **31개 통과, 실패 0개, 건너뜀 0개**.
- 본인 접근 허용, 타인·비로그인 읽기/쓰기/수정/삭제 차단, 잘못된 메타데이터·시각 거부를 실제 로컬 규칙에서 확인했습니다.
- v1 읽기·v2 재저장, 생성 시각 유지, 사진/미리보기 제외, 알 수 없는 버전 거부를 확인했습니다.
- 일반 모델·VLM·skip connection·중첩 Add·Add 입력 3개의 블록 ID·위치·매개변수·연결·클래스 순서 복원을 검증했습니다.
- 복원 전후 PyTorch/Keras 코드 문자열과 Colab 셀 내용이 동일합니다. 이 검사는 코드 생성의 회귀를 확인하며, 외부 Python 런타임에서의 학습 실행을 보장하지 않습니다.

브라우저 검증은 `.env.local`을 읽지 않는 전용 demo 서버와 로컬 Auth/Firestore Emulator에서 진행했습니다.
Hugging Face 응답은 고정된 테스트 splits/fields를 사용했으며, 실제 이미지나 외부 데이터셋 행은 내려받지 않았습니다.

- 캔버스가 첫 화면으로 열리고, 저장 버튼과 로그인 버튼이 같은 상단 바에 표시됩니다.
- 새 저장·목록·같은 문서 재저장·덮어쓰기 확인·불러오기를 확인했습니다.
- VLM의 블록 ID·위치·연결과 데이터셋 validation split이 복원됐습니다.
- skip 모델의 블록 6개·연결 6개가 동일하게 복원되고 Colab 노트북 파일이 다운로드됐습니다.
- 작은 CNN(합성 사진 15장, 입력 32, 필터 2)에서 실제 1에폭 학습 완료를 확인했습니다. 추가 학습 중에는 불러오기 버튼이 비활성화됐습니다.
- 큰 기본 CNN의 장시간 학습 시도는 브라우저 연산이 오래 걸려 제한 확인에 적합하지 않았습니다. 완료 여부를 단정하지 않고 작은 모델로 다시 검증했습니다.
- 3D WebGL 캔버스 생성, 화면 이동, 계정별 목록 분리, 계정 변경/로그아웃 후 캔버스·데이터 패널·작업 초기화를 확인했습니다.

- 웹캠·MobileNet 가중치 다운로드·Colab 내부 실행·배포는 이번 검증에 포함하지 않았습니다.
